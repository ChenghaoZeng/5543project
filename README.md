To access the microdata from the Australian Bureau of Statistics (ABS), go to https://microdatadownload.abs.gov.au/MicrodataDownload/login.xhtml
 and download the following datasets:

1: Income and Housing, 2019–20

2: Income and Housing, 2013–14

Please note that you will need to sign in using an authorised organisational account (e.g. a Monash University account) to access the microdata.

The data dictionaries can be found under the Description column and can be downloaded by clicking the highlighted text labelled “Data Item List.”
